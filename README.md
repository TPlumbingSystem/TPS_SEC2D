# TAIÓ — Seção 2D Interativa

Mapa em planta + seção transversal interativa (Plotly, HTML autônomo) do sistema
intrusivo de Taió (SC) — sill/soleira e dique de diabásio intrudindo formações
sedimentares da Bacia do Paraná.

Abra `secao_interativa.html` direto no navegador.

Identidade visual TAIÓ — Sistema Intrusivo · Plumbing System. Complemento dos outros
produtos: [TPS_HUB](https://github.com/TPlumbingSystem/TPS_HUB) (página inicial),
[TPS_MOD3D](https://github.com/TPlumbingSystem/TPS_MOD3D),
[TPS_DASH](https://github.com/TPlumbingSystem/TPS_DASH),
[TPS_WEBM](https://github.com/TPlumbingSystem/TPS_WEBM).

Gerado por `gerar_secao_interativa.py` (Python, Plotly) — depende dos dados do
projeto completo, não roda de forma standalone fora dessa estrutura; incluído aqui
como referência/histórico do código.
